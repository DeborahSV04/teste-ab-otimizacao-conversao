Teste A/B e Otimização de Conversão

Descrição do projeto

Este projeto analisa os resultados de um experimento A/B realizado para avaliar mudanças no comportamento dos usuários e identificar oportunidades de otimização da conversão.

A análise também utiliza os frameworks ICE e RICE para priorizar hipóteses de negócio, considerando impacto, confiança, esforço e alcance.

Objetivos

* Priorizar hipóteses utilizando os frameworks ICE e RICE.
* Analisar os resultados de um experimento A/B.
* Comparar a receita acumulada dos grupos A e B.
* Investigar o tamanho médio dos pedidos.
* Avaliar as taxas de conversão.
* Identificar e tratar valores atípicos.
* Aplicar testes estatísticos para comparar os grupos.
* Formular uma recomendação baseada nos resultados.

Ferramentas e tecnologias

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SciPy
* Jupyter Notebook

Etapas da análise

1. Exploração e preparação dos dados.
2. Priorização de hipóteses com os métodos ICE e RICE.
3. Verificação da distribuição dos usuários entre os grupos.
4. Análise da receita acumulada e do tamanho médio dos pedidos.
5. Avaliação das taxas de conversão.
6. Identificação de valores atípicos.
7. Filtragem de dados para análise complementar.
8. Realização de testes estatísticos com dados brutos e filtrados.
9. Interpretação dos resultados e definição de uma recomendação.

Principais resultados

* O framework ICE e o framework RICE apresentaram diferentes prioridades para as hipóteses, demonstrando a importância de considerar o alcance das iniciativas.
* O grupo B apresentou uma taxa de conversão estatisticamente superior à do grupo A.
* Nos dados brutos, não foi identificada diferença estatisticamente significativa no tamanho médio dos pedidos.
* Após a filtragem dos valores atípicos, a vantagem de conversão do grupo B permaneceu estatisticamente significativa.

Conclusão

Os resultados indicaram melhor desempenho do grupo B em relação à conversão, tanto na análise dos dados brutos quanto na análise após a filtragem de valores atípicos.

Com base nas evidências obtidas, a recomendação do projeto foi encerrar o teste A/B e considerar o grupo B como a alternativa de melhor desempenho.
